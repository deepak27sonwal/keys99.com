In Maharashtra, almost every new residential project must be registered with MahaRERA, the state's real estate regulator, before it can be advertised or sold. Checking a project's registration takes a few minutes and is the single most useful check before you pay a booking amount.

Step 1: Find the registration number

A project's MahaRERA number starts with the letter P followed by digits. It must appear on the project's brochures and advertisements, and on its Keys99 project page. If the developer or agent cannot give you one, treat that as a warning sign. A real estate agent has a separate registration number, which starts with A.

Step 2: Look it up on the MahaRERA website

  1. Open the official MahaRERA website (maharera.maharashtra.gov.in).
  2. Go to the search for registered projects.
  3. Enter the registration number, or search by project name, district and promoter.
  4. Open the project's details page.

Make sure the project name, promoter (developer) and address on MahaRERA match what you were told.

Step 3: Check these details

  • Proposed completion date: the date the developer has committed to. Compare it with the possession date in your agreement.
  • Building plans and approvals: the sanctioned plans and approvals uploaded for the project.
  • Progress updates: developers must update the project's progress on MahaRERA regularly. Long gaps, or progress far behind the timeline, are worth asking about.
  • Complaints: any complaints filed against the project or the promoter.
  • Promoter's other projects: how the developer's earlier projects have done.

What RERA registration does and does not mean

Registration means the project is on record with the regulator and must follow RERA's rules: for example, the developer has to keep 70% of the money collected from buyers in a separate account for that project, and must deliver by the committed date or face penalties. It is not a guarantee of quality or a recommendation. You should still check the title, the approvals and the developer's track record.

Projects outside Maharashtra

Every state has its own RERA authority and website. For projects in Hyderabad, use Telangana RERA (rera.telangana.gov.in). The checks above apply in the same way.

Every project on Keys99 shows the RERA number provided for it. Browse projects and check the number on the RERA website before you visit.

How do I know if a project is RERA registered?

Search the project's registration number, or its name, on the state RERA website, such as MahaRERA for Maharashtra. A registered project has a details page showing its promoter, approvals and completion date.

What does a MahaRERA project number look like?

A MahaRERA project registration number starts with the letter P followed by digits. Agent registration numbers start with the letter A.

Is it safe to buy in a project that is not RERA registered?

Most new projects must be registered before they are advertised or sold. If a project that should be registered is not, you lose the protections RERA gives buyers, so ask why before you pay anything.
